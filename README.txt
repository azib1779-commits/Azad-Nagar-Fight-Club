AZAD NAGAR FIGHT CLUB - FIGHTERS WEBSITE

This fresh version is ONLY for fighter and match information.
No payments, memberships, checkout, accounts or admin dashboard.

Sections:
- Home
- Fighters / Boxers
- Upcoming Matches
- Recent Results
- Gallery
- Contact

FILES:
index.html  -> website structure/content
style.css   -> responsive black/red design
app.js      -> fighter, match and result data + rendering

HOW TO CUSTOMIZE:
Open app.js and edit the fighters, matches and results arrays.
Replace image URLs with your own fighter/club photos.

DEPLOY:
Upload all 3 website files (index.html, style.css, app.js) to GitHub Pages.
